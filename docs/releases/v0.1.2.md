## 바뀐 점

### 🐞 고침
- **Linux: 트레이 호스트가 앱보다 늦게 뜨면 비정상 종료(SIGSEGV)되던 문제** — 로그인 직후 자동 실행, GNOME 셸 재시작, AppIndicator 확장을 나중에 켤 때 발생했습니다(v0.1.0·v0.1.1). 이제 호스트가 나타나거나 다시 시작되면 다시 등록합니다.
- **Linux: 설치 후 앱 목록에 보이지 않던 문제** — `install.sh`가 실행 경로를 절대 경로로 쓰고, 다른 앱이 만든 아이콘 캐시가 있으면 갱신합니다.
- **Windows: 대기 중 화면 배율을 바꾸면 트레이 아이콘이 옛 크기로 남던 문제** — 배율·디스플레이 변경 알림에서 현재 DPI로 다시 그립니다.

### ✨ 개선
- **Linux: GNOME 패널에서 숫자가 또렷해졌습니다** — 16px 아이콘을 함께 보내 축소로 흐려지지 않습니다.
- **Linux: 로그인 시 자동 실행** — `./install.sh --autostart`. `./uninstall.sh`가 함께 지웁니다.

## 설치
| OS | 방법 |
| --- | --- |
| Windows | `winget install SosomLab.NexaCoffee` · `choco install nexa-coffee`(검수 후 노출) · 또는 zip |
| macOS | `brew install --cask kiros33/tap/nexa-coffee` |
| Linux | `brew install kiros33/tap/nexa-coffee-portable` · 또는 tar.gz를 풀고 `./install.sh`(로그인 자동 실행은 `--autostart`) |
