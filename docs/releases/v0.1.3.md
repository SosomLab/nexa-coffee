## 바뀐 점

### ✨ 새 기능
- **트레이 메뉴 "로그인 시 실행"(Windows · macOS · Linux)** — 체크하면 로그인할 때 자동으로 실행됩니다. 켜짐 여부는 OS 설정을 그대로 읽으므로, 설치 프로그램이나 `install.sh --autostart`로 켠 것도 메뉴에 체크로 보입니다.
  - Windows: 사용자 시작 프로그램(레지스트리 `Run`) · macOS: 사용자 LaunchAgent · Linux: `~/.config/autostart`
- **Windows 설치 프로그램** — `nexa-coffee-0.1.3-windows-setup.exe`
  - 관리자 권한 없이 사용자 폴더(`%LOCALAPPDATA%\Programs\NexaCoffee`)에 설치되며, 64비트·32비트 Windows를 한 파일로 지원합니다.
  - 설치 마법사에서 **"로그인 시 실행"**을 고를 수 있습니다(기본은 꺼짐).
  - 무인 설치: `/S` · 로그인 시 실행까지 켜려면 `/S /AUTOSTART=1`
  - 업그레이드·제거 때 실행 중인 앱을 자동으로 닫습니다. 제거해도 설정은 남습니다.
- **언어 ▸ "시스템 (한국어)"** — 언어 메뉴 맨 위에 OS 표시 언어가 보입니다. 고르면 저장된 언어를 지우고 OS 언어를 따릅니다. 이전에는 한 번 언어를 고르면 OS 언어로 돌아갈 방법이 없었습니다.
  - 언어를 바꾸면 메뉴와 툴팁에 바로 적용됩니다. Windows·macOS는 OS 언어를 바꿔도 곧바로 따라갑니다.

## 알려진 한계
- **Linux(deb/rpm)**: `apt remove`·`dnf remove`는 사용자 폴더의 `~/.config/autostart/nexa-coffee.desktop`을 지우지 못합니다. 지우기 전에 메뉴에서 "로그인 시 실행"을 끄거나 파일을 직접 지우세요(남아 있어도 해는 없습니다).
- **macOS 13 이상**: "로그인 시 실행"을 켜면 OS가 "백그라운드 항목 추가됨" 알림을 띄웁니다(정상 동작).
- **Linux**: OS 언어를 바꾸면 앱을 다시 실행해야 "시스템" 언어에 반영됩니다.
- 코드 서명이 없어 Windows SmartScreen·macOS Gatekeeper 경고가 뜰 수 있습니다.
