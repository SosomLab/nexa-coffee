## 바뀐 점

### 🛡️ Windows: 설치 프로그램이 백신에 막히던 문제 수정
0.1.5 설치 프로그램(`nexa-coffee-0.1.5-windows-setup.exe`)이 Windows Defender(`Trojan:Win32/Suschil!rfn`) 등 일부 백신에서 오탐으로 차단됐습니다.

- 원인은 앱이 아니라 설치 프로그램을 만드는 도구(NSIS) 쪽이었습니다. 빌드 환경을 공식 NSIS로 바꿨습니다.
- 새 설치 프로그램은 Windows Defender 검사에서 위협이 발견되지 않았습니다.
- 설치 프로그램 파일 정보(버전 리소스)도 보강했습니다.
- **0.1.5 설치 프로그램을 받다가 막혔다면** 0.1.6 설치 프로그램을 받으면 됩니다.

### 앱 자체는 0.1.5와 같습니다
macOS·Linux·Windows 포터블은 기능 변화가 없습니다. 업데이트해도 되고 안 해도 됩니다.

## 설치
| OS | 방법 |
| --- | --- |
| Windows | 설치 프로그램 `winget install SosomLab.NexaCoffee` · `choco install nexa-coffee` / 포터블 `winget install SosomLab.NexaCoffee.Portable` · `choco install nexa-coffee-portable` |
| macOS | `brew install --cask kiros33/tap/nexa-coffee` · 업데이트 `brew upgrade --cask nexa-coffee` |
| Linux | [pkg.sosomlab.com](https://pkg.sosomlab.com/) 저장소 등록 후 `sudo apt install nexa-coffee` / `sudo dnf install nexa-coffee` · `brew install kiros33/tap/nexa-coffee-portable` · 또는 tar.gz를 풀고 `./install.sh` |

## 알려진 한계
- **macOS**: 덮개를 닫아 생기는 절전은 OS 강제 절전이라 앱이 막을 수 없습니다.
- **Linux(deb/rpm)**: `apt remove`·`dnf remove`는 `~/.config/autostart/nexa-coffee.desktop`을 지우지 못합니다. 지우기 전에 메뉴에서 "로그인 시 실행"을 끄세요.
- 코드 서명이 없어 Windows SmartScreen·macOS Gatekeeper 경고가 뜰 수 있고, 백신에 따라 오탐이 다시 생길 수 있습니다. 확인한 것은 Windows Defender 검사뿐입니다.
- winget·Chocolatey 설치 프로그램 패키지는 각 저장소의 검수를 거친 뒤 검색됩니다.
