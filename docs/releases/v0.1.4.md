## 바뀐 점

### 📦 Windows 배포가 설치 프로그램과 포터블로 나뉩니다
앱 자체는 v0.1.3과 같습니다. 이번 버전은 Windows 배포 구성만 바뀌었습니다.

| 구분 | 설치 프로그램 | 포터블(압축 풀고 실행) |
| --- | --- | --- |
| 직접 받기 | `nexa-coffee-0.1.4-windows-setup.exe` | `nexa-coffee-0.1.4-windows-x64-portable.zip` · `-windows-x86-portable.zip` |
| winget | `winget install SosomLab.NexaCoffee` | `winget install SosomLab.NexaCoffee.Portable` **(새 패키지)** |
| Chocolatey | `choco install nexa-coffee` | `choco install nexa-coffee-portable` **(새 패키지)** |

- 포터블 zip 이름에 `-portable`이 붙었습니다(안의 실행 파일 `nexa-coffee-x64.exe` · `nexa-coffee-x86.exe`는 그대로).
- 설치 프로그램은 관리자 권한 없이 사용자 폴더에 설치되고, 시작 메뉴·설치된 앱 목록에 등록됩니다. "로그인 시 실행"을 함께 켜려면:
  - 직접 실행: 설치 마법사에서 선택 · 무인 설치 `/S /AUTOSTART=1`
  - Chocolatey: `choco install nexa-coffee --params "'/AutoStart'"`
- ⚠️ **Chocolatey `nexa-coffee`를 쓰던 분**: v0.1.3까지 이 패키지는 포터블이었습니다. 업그레이드하면 설치 프로그램 방식으로 바뀝니다. 계속 포터블을 원하면 `choco uninstall nexa-coffee` 후 `choco install nexa-coffee-portable`.
- 새 패키지(`SosomLab.NexaCoffee.Portable` · `nexa-coffee-portable`)는 각 저장소의 검수를 거친 뒤 검색됩니다.

## 설치
| OS | 방법 |
| --- | --- |
| Windows | 위 표 |
| macOS | `brew install --cask kiros33/tap/nexa-coffee` |
| Linux | [pkg.sosomlab.com](https://pkg.sosomlab.com/) 저장소 등록 후 `sudo apt install nexa-coffee` / `sudo dnf install nexa-coffee` · `brew install kiros33/tap/nexa-coffee-portable` · 또는 tar.gz를 풀고 `./install.sh` |

## 알려진 한계
- **Linux(deb/rpm)**: `apt remove`·`dnf remove`는 사용자 폴더의 `~/.config/autostart/nexa-coffee.desktop`을 지우지 못합니다. 지우기 전에 메뉴에서 "로그인 시 실행"을 끄거나 파일을 직접 지우세요(남아 있어도 해는 없습니다).
- **macOS 13 이상**: "로그인 시 실행"을 켜면 OS가 "백그라운드 항목 추가됨" 알림을 띄웁니다(정상 동작).
- **Linux**: OS 언어를 바꾸면 앱을 다시 실행해야 "시스템" 언어에 반영됩니다.
- 코드 서명이 없어 Windows SmartScreen·macOS Gatekeeper 경고가 뜰 수 있습니다.
