## 판단
- **언어 = C**(DR-1). Rust는 std 바이너리 최소 수백 KB. nexa-shortcut(4.5 KB C)과 같은 원칙으로.
- **코어 libc 금지**(DR-2): Windows CRT 미링크를 지키려면 코어가 memset/sqrt/atan2를 부르면 안 된다 → 정수 atan2/sin LUT(tools 생성) · 4×4 슈퍼샘플 커버리지 · straight-alpha over 합성.
- **Linux libdbus 없이**(DR-3): SASL EXTERNAL · UNIX_FD 협상 · 마샬러/언마샬러 ~500줄. musl 정적 → libc 하나.
- **UI = 메뉴만**(DR-4): 사용자 지정 = 서브메뉴 일(0~7)·시간(0~23)·분(5단위) + "시작 — 요약". 창 코드 0.
- 24h 이상은 **일** 단위(보라) 추가 — 사용자 지정에 일이 들어와서. 값은 단위별 내림(1h59m → "1").
- 덮개 닫힘(DR-8): Windows/macOS는 관리자 정책. Linux만 logind `handle-lid-switch` block.

## 문제와 해결
- 16px 두 자리 숫자 흐림 → 글리프 칸이 1~2px 사이면 1px로 고정하고 원점을 픽셀 격자에 스냅(`icon_active.c layout_text`).
- macOS `dbus-daemon --session`은 launchd 소켓 요구 → `scripts/dbus-test.conf`(unix:tmpdir · EXTERNAL)로 띄운다. CI 컨테이너에서도 같은 설정.
- `grep -q`가 파이프를 일찍 닫아 echo SIGPIPE → `has()`로 끝까지 읽기.
- `XDG_CONFIG_HOME` 상위 폴더가 없으면 설정 저장 실패 → conf_init에서 두 단계 mkdir.
- Docker Desktop 백엔드가 이 세션에서 종료돼 컨테이너 검증은 못 했다(스크립트는 준비: `scripts/linux-docker.sh`).
- System Events로 메뉴 열기 실패(접근성 권한) — 메뉴 스크린샷은 없다. 메뉴 트리는 test_core로 검증.
