### choco 0.1.2 제출
- `gh workflow run publish-windows-packages.yml -f tag=v0.1.2 -f channels=choco -f force=true` → run [36543966975](https://github.com/SosomLab/nexa-coffee/actions/runs/36543966975) **success**(guard 7s · chocolatey 27s · winget 건너뜀).
- 로그: `Successfully created package 'nexa-coffee.0.1.2.nupkg'`(3,741 B) → `nexa-coffee.0.1.2.nupkg was pushed successfully to https://push.chocolatey.org/`.
- `force=true`가 필요했던 이유: 가드는 **직전 태그(v0.1.1)**가 피드에 있는지로 검수 대기를 판정하는데, 0.1.1은 choco에 올리지 않았다 → force 없이는 영원히 "대기"로 건너뛴다.
- winget 잡의 `winget validate` 경고(exit 40)는 `channels=choco`로 건너뛴 잡의 참고 산출물 — 09-17에 경고로 통과 처리한 그 경고.
- 0.1.2는 아직 피드 비공개(모더레이션 중). 승인된 패키지의 새 버전이라 첫 제출보다 빠를 수 있다.
